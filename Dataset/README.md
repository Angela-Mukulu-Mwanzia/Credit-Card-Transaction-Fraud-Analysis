# Dataset source

The analysis uses `../Credit Card Transactions Dataset/credit_card_transactions.csv`.

Source: [Kaggle - Credit Card Transactions Dataset](https://www.kaggle.com/datasets/priyamchoksi/credit-card-transactions-dataset).

The CSV is intentionally kept in its supplied folder to avoid committing a duplicate large file. In Power BI, set the source path to this CSV, then use a relative/parameterised path before publishing the report.
